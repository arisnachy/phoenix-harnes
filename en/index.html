07 / FAQ

Frequently asked questions

Is PHOENIX free?

The code is MIT-licensed and the site, documentation and public resources are free. Some external providers may charge. Choose local resources or supported free tiers.

Do I need an API key?

It depends on the engine. Local models may run without an external key. Remote services require authorized credentials or account connections.

Does it work completely offline?

Local inference and some tools can work offline after dependencies and models are installed. Web search, remote services and updates require network access.

Is everything production-ready?

PHOENIX is in active development. Availability depends on the build and verification. Healthia is not presented as a certified medical device. Sports research does not guarantee outcomes.

Can I contribute?

Yes. Read the contribution guide, report reproducible issues and share results without exposing credentials or personal data.
