# Jungle Echo — PHOENIX Game Studio 纵向切片

[English](README.md) | 中文

这是一个**原创、离线运行**的 2D 横版射击技术起点。它**不**使用《魂斗罗》的美术资源，也**不能**作为达到成品级角色美术质量的证据。

## 运行方式

在现代浏览器中打开 `jungle-echo.html`，或将其完整 HTML 内容作为 MIME `application/vnd.phoenix.game+html` 发布到 PHOENIX 聊天工件。预览在隔离的 iframe 中执行内联脚本，不依赖外网或 CDN。

- 左右方向键或 A/D：移动
- 空格 / 上方向键 / W：跳跃
- J/K：射击
- M 或 **Sonido: encender**：切换音乐与音效（需要用户操作激活浏览器音频）
- 屏幕控制按钮：触摸输入
- Reiniciar：重置游戏

## 已根据源码检查

- 内嵌清单声明原创美术、主角状态和动画、两种敌人、双阶段首领、关卡几何与图层以及音频事件。
- 游戏循环采用固定时间步长、位置相关绘制、跳跃物理、动态视差、敌方弹丸、粒子和随首领阶段变化的攻击节奏。
- 仅使用内联 HTML、CSS、JS 和浏览器 Canvas/WebAudio，不需要远程依赖或第三方素材。

## 局限性

- 程序化绘制与骨架式形状只是运动和物理参考，不能替代高分辨率精灵表、高级着色器、专门制作的原创图像或编曲音频。
- 检查结构清单**不等于**视觉或听觉质量保证。商业发布前应在真实浏览器和设备上运行，检查截图与动画，通过用户交互测试 WebAudio，核查无障碍使用并针对目标硬件优化。
- 研究引用不会凭空捏造；工作流程要求 Kira 在每次根据参考游戏开发新作品时搜索并记录真实参考来源。

工作流程文件 .agents/skills/phoenix-game-studio/SKILL.md 说明了 La Forja 的有限并行流程、许可要求、质量标准及停止条件。
