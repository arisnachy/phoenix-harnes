# Phoenix / Godot Game Studio foundation

**Status: PROTOTYPE.** This is a real Godot 4 project with a controllable hero
(arrow keys, J shoot, H whip, L magic), a moving boss with two phases,
telegraphed bullet/fan/wave attacks, hits, cooldowns and a native smoke test.

## Before claiming a completed game
- Replace geometric prototype drawings with original/approved actor sprite
  atlases linked to AnimatedSprite2D or AnimationPlayer; include idle, walk,
  jump, attack, magic, hurt, death and boss-phase clips as requested.
- Supply each enemy, separate level parallax/tiles, real effects and
  licensed/original background music, shots, whip, impacts and spoken voices.
- Verify project import, in-game screenshots, controls, damage, victory,
  phase changes, real sound playback and export templates/platform artifacts.
- Godot native/Web exports are not single-file HTML. For a game in Phoenix
  chat, provide and test a separately packaged HTML5 Canvas version.

This scaffold proves the engine/toolchain wiring only. It is NOT a finished
high-quality game and contains no professional audio recordings.
