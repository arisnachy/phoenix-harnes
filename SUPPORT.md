# PHOENIX support

- Use [Discussions](https://github.com/arisnachy/phoenix-harnes/discussions) for setup, providers, models, ideas, and general questions.
- Use [Issues](https://github.com/arisnachy/phoenix-harnes/issues) for reproducible defects and scoped feature requests.
- Use [private security reporting](https://github.com/arisnachy/phoenix-harnes/security/advisories/new) for vulnerabilities.

Before reporting a runtime defect, include the PHOENIX commit, Windows version, Node version, selected provider/model, exact command, and redacted error. Never post credentials or full session logs containing personal data.
