# Community code of conduct

PHOENIX welcomes respectful collaboration across experience levels, languages, identities, and backgrounds. Be constructive, discuss evidence and code rather than people, respect privacy, and do not harass, threaten, discriminate, publish private information, or pressure anyone to reveal credentials.

Maintainers may edit or remove abusive content and restrict participation when necessary to protect the community. Report conduct concerns privately through the repository maintainers; security vulnerabilities must use the separate process in `SECURITY.md`.
