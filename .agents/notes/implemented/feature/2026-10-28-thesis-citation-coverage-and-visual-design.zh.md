# Agent Note: 学位论文参考文献建议与可溯源的视觉排版

Status: implemented

[English](2026-10-28-thesis-citation-coverage-and-visual-design.md) | 中文

## Problem

现有研究发布工具对所有学位论文采用统一的内部 15 项来源下限，没有区分学士、硕士和博士论文，也没有明确展示不同学位的参考文献目标。APA 引文在 HTML 阅读页中被错误编号。不同大学可能有更严格的校内规范，而美观的图表不能依靠虚构数据生成。

## Decision

学术规划工具识别本科、硕士、博士论文，并分别提供 20–40、40–80 和至少 100 项不同且已引用来源的建议。这些数字不是通用法规。经过用户审阅的学校 `min_references` 可覆盖建议，并由 TypeScript 与 Python 两层发布器执行。学位论文必须明确选择 APA 7 或 Vancouver，并保留正文引用与文献记录的关联校验。APA 采用作者—年份方式和按作者排序、无编号、悬挂缩进的文献表；Vancouver 采用数字引用和首次出现顺序。HTML 阅读页也遵守这一差异。

视觉计划支持高级排版偏好，但不会破坏严格的学校或期刊格式。混合阅读版本可使用研究紫或临床青配色；正式学术提交仍保留传统布局。图表和表格必须具有真实的来源键和可追溯数据，不能编造数值或标志。

## Alternatives considered

**低于建议数量就拒绝所有论文：**这会把参考目标误当成所有大学必须遵守的法规，因此不采用。

**补充虚构文献或图表以达到数量：**损害证据可信度，因此拒绝。

**给学校正式提交件增加装饰封面：**可能违反学校的格式规定，所以仅在混合阅读版使用增强设计。

## Consequences

规划工具会在写作前提供引用和来源建议。发布回执将经过审阅、具有约束力的学校最少来源要求与非阻断性的参考建议分开。仍需验证真实页数、来源和研究深度，并由人类复核；所选样式不能自动保证学校合规或外部文献真实。

## Testing

规划与 TypeScript 发布测试覆盖各学位目标、APA/Vancouver、视觉偏好和学校要求；Linux/Windows 冒烟测试验证 HTML 文献表格式，以及不合法引文规范与未达学校要求时的拒绝行为。
