# Agent Note：自然语言创建游戏时自动加载 Game Studio

Status: implemented

[English](2026-10-18-natural-game-creation-intent.md) | 中文

## Problem

用户被迫提供工具名称、内部文件路径和发布步骤，才能要求创建游戏。技能目录虽然包含 Game Studio，模型仍可能只规划、调查或委派任务，而没有先加载实际操作技能。这不符合通用助手的意图优先设计。

## Decision

通用技能加载器增加了一项明确的创建意图识别：当用户使用西班牙语或英语提出诸如「haz un juego de carreras」或「make a game about space」的请求时，直接加载已安装的 **game-development** 技能。用户无需指定游戏类型目录、路径、引擎、技能名称或发布工具。模糊请求仍通过模型目录判断。识别器位于独立的 `natural-intent.ts` 文件中，不改变通用技能加载器的生命周期。

自动激活只考虑用户直接输入的文本，并要求技能可供模型使用、工具可见。显式 `/skill` 请求保持原有规则，避免重复加载。外部文本和工具返回信息无法触发自动激活。Game Studio 的说明要求依照用户指定的类型、玩法和交付目标创建游戏，而不是默认重复同一份清版动作模板。

## Validation

测试覆盖多种游戏类型、自然语言询问、拒绝与解释类请求、外部来源、技能缺失及显式技能调用。它们验证路由，而不是最终游戏品质或真实发布。

## Consequences

Kira 不再依赖用户指挥内部步骤来加载游戏制作技能。不过，完整制作、测试和发布依然需要真实运行时能力，自动激活本身不是完成证明。

## Alternatives considered

要求用户明确指定并调用 Game Studio 技能。此方案暴露内部实施步骤，也使普通自然语言请求无法直接激活已安装且获授权的技能，因此未采用。
