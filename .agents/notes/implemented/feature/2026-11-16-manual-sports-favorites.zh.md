# Agent Note：独立体育收藏球队与实时状态

状态：已实现

## 问题

之前的比分卡将关联票据的跟踪与 Kira 预测视为一个可见的选择，而且缺少用户针对每场比赛的手动选择。当两种记录同时存在时，预测选择可能被隐藏，也无法独立统计用户自己的赛前选择。

## 决策

浏览器本地记录按 ESPN 赛事 ID、项目、联赛、日期、主客队完全匹配的个人选择。标记明确表示“用户选择”，不代表赔率、下注成功或庄家结算。Kira 的结构化预测与真实票据目标独立显示，可以指向相同或相反球队；聊天卡片仍保持紧凑的每行两场布局。

只有赛事 ID 和主客队同时匹配才允许按比分评估实时和最终状态。统一逻辑给出待开始、领先、落后、获胜、失败或待复核的小图标和临时结果标签；过期的实时比分不得被当作已确认结果。开赛后所选球队只作跟踪，不纳入预测准确率；本地准确率只计入已观察到对应最终比分的赛前选择。确认终场后不能修改选择。

界面保留现有 `data-selected-favorite`、`data-pick-source` 与“临时结果”标签以兼容回归测试。功能需要逐场主动使用，不请求庄家凭据。

## 验证

界面测试覆盖选择、修改、清除、刷新、与 Kira 不同的选择、实时与终场、赛事 ID 不匹配及开赛后选择不计入准确率。只有用户访问过终场比赛才会更新浏览器本地历史，这不是完整的历史回测。CI 和设备验证与代码实现分开进行。
