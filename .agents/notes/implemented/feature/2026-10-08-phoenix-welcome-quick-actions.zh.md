# Agent Note：温暖且可操作的 Phoenix 欢迎页

Status: implemented

[English](2026-10-08-phoenix-welcome-quick-actions.md) | 中文

## Problem

此前的新会话界面与获批的温暖、宽敞的视觉参考不一致；快捷操作组件还可能绕过真实工作区和编辑器状态。

## Decision

Phoenix 欢迎页显示居中的品牌标志、问候语、两行快捷操作卡片、建议标签和较宽的输入框。快捷操作与建议仅向现有 InputHub 写入草稿；不会提交消息、切换模型或调用工具。尚无工作区时，Phoenix 会打开既有的工作区选择器，在真实会话可用前保留草稿。欢迎页与活跃聊天页共享始终挂载的同一个文本输入框。

只有欢迎页的主视觉阶段可以扩展到 1000px；活跃对话仍保持 768px 的内容宽度。侧边栏的变化仅涉及间距和现有的新建会话控件。

## Alternatives considered

**增加第二个欢迎页输入框。** 已拒绝，因为重复的输入框会与真实输入会话不同步，并可能丢失草稿。

**让快捷操作立即提交。** 已拒绝，因为建议标签应保持为用户控制的草稿，而不能触发尚未批准的操作。

## Consequences

欢迎界面获得获批的布局，但正常聊天状态、工作区选择和模型选择继续保持权威。验证需要定向 UI 测试，覆盖草稿复用、缺失工作区、响应式 3/2/1 列卡片以及键盘焦点。深色模式、活跃聊天尺寸和真实浏览器渲染仍需独立审查；仅提交源文件并不能证明视觉正确。
