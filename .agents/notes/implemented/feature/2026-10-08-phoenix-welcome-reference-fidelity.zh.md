# Agent Note：Phoenix 欢迎界面与批准的参考设计保持一致

Status: implemented

[English](2026-10-08-phoenix-welcome-reference-fidelity.md) | 中文

## Problem

之前的快捷操作实现虽然重现了卡片，却遗漏了已批准参考中的导航、顶部工具栏和内容对齐。

## Decision

实际展开的侧边栏包含 Inicio、Descubrir、Conectores、Equipo 和 Biblioteca。Inicio 复用 `startSession`；中间三个入口打开已注册的目的地；Biblioteca 和欢迎页搜索调用现有的工作区会话搜索。折叠侧边栏不会破坏工作区和导航路径。

欢迎工具栏使用现有会话模型目录中的真实模型选择器。活动输入框仅在空白欢迎阶段调整选择器位置；不会引入第二个文本框或虚构的模型操作。头像打开真正的个人资料设置。

居中的欢迎主体不再继承悬浮团队面板导致的偏移：280px 侧边栏下原来大约偏移 112px。保留真实的单色 Phoenix 徽标和只显示首字母的头像。

## Alternatives considered

**添加静态导航插图。** 已拒绝，因为插图无法打开真实目的地，会暗示不存在的功能。

**复制模型选择器和输入框逻辑。** 已拒绝，因为会话状态和可用模型将出现互相竞争的权威来源。

**在个人资料控制中使用虚构人物头像。** 已拒绝，改用实际支持的首字母头像。

## Consequences

欢迎页更接近已批准的参考设计，同时不会引入影子导航或重复会话状态。最终仍需在精确 commit 上构建，并在真实桌面和移动端测试模型菜单、设置导航、工作区搜索、焦点行为以及明暗主题。
