# PHOENIX-wide evolution discovery and presentation adaptation

Issue [#2042](https://github.com/arisnachy/phoenix-harnes/issues/2042).

The common Living toolset, not an ORION provider route, owns self-assessment. Its result now exposes domain-specific discovery paths and actual registered Cordis lifecycle tools. The result grants no execution authority. Existing owning services, approval flows, and independent promotion rules remain authoritative. Temporary Cordis definitions are not durable source changes. The root AppFrame now reports resolved frame geometry and adapts constrained ordinary chat as well as specialized workspaces; existing manual expansion and layout ownership remain intact.

Focused regression cases cover partial tool availability, model-independent discovery, and the wide-sidebar ordinary-chat case. A trusted persistent change supervisor, global settings mutation contracts, background initiative and end-to-end source promotion remain outside this increment. No claims of unrestricted autonomous source modification are made.
