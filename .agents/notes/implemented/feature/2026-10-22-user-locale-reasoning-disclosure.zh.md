# Agent Note: 根据执行事实呈现推理活动并遵循用户语言

Status: implemented

[English](2026-10-22-user-locale-reasoning-disclosure.md) | 中文

## Problem

原有推理面板重复显示固定提示，无法区分真实工具执行记录与模型可能保密的内部推理。用户已在 PHOENIX 设置中选择语言时，系统提示却仍以最新消息的语言为准，切换模型后可能出现语言不一致。

## Decision

现有 Tools 分组为每个推理步骤提供默认收起的面板，只有用户主动展开后才列出该分组中已经记录的工具名称和真实运行状态。运行中、失败和完成等状态使用当前客户端语言。面板不输出模型的私有推理文本、工具参数或结果；没有可公开的工具事件时明确说明，不虚构计划或结论。英语和西班牙语界面会隐藏包含非拉丁文字的工具名称，但保留原始事件。

当用户明确保存语言偏好且设置和系统提示服务均可用时，Host 的语言插件会向模型加入动态指令，要求以所选语言作答，并以该语言输出可公开的决策说明。缺少明确偏好时保留原行为。此功能不是自动翻译服务，不会改写路径、命令、引用或标识符。

## Alternatives considered

**直接公开服务商的原始推理。** 不采用：某些适配器只提供内部推理，没有证明内容可以公开的标识，可能造成隐私和安全问题。

**使用预设推理步骤。** 不采用：预设内容不能证明真实执行，可能误导用户。

**在浏览器翻译流式内部推理。** 不采用：渲染组件没有可信的翻译通道，延迟翻译还可能暴露原文片段。

## Consequences

用户可以查看可核验的工具活动，而不是反复阅读固定隐私提示。若模型不提供可公开的推理摘要，面板只报告真实执行信息，不冒充私有思维内容。未来可在明确标记公开来源时加入授权摘要。模型正文的语言偏好仍依赖服务商遵从；并不保证翻译第三方工具输出，也不能检测所有使用拉丁文字的语言不一致。

## Verification

聚焦测试覆盖用户主动展开、真实工具状态更新、无证据情况、语言切换、异常文字隐藏、私有内容隔离，以及 Host 语言偏好。发布前仍需验证完整 Web 应用及不同服务商。
