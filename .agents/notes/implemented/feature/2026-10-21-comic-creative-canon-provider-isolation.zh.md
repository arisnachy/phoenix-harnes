# Agent Note: 漫画创意设定锁定与外部工具隔离

Status: implemented

[English](2026-10-21-comic-creative-canon-provider-isolation.md) | 中文

## 问题

持久化画稿和图像生成记录只能保存文件和调用结果，不能保存用户批准的艺术目标。用户可能同时提供已生成的插画与希望实现的封面、分镜和封底示例。若混淆这些用途或让外部排版工具自行解释整个作品，就会在超时、换工具和恢复对话时改变故事、角色和画风。

## 决策

`scripts/phoenix-comic-canon.mjs` 在现有 Comic Studio 系列目录内保存按系列和期数隔离的创意合同。合同记录情节概要、逐页叙事、人物形象、画风、配色、禁用元素、编辑版式、封面要求以及通过 SHA-256 校验的本地图像。每张参考图标有明确角色：已生成作品、风格或人物锚点、气氛示例、封面目标、封底目标或分镜目标。合同可以提出草案，但锁定需要归属于用户的明确批准和匹配的摘要，之后不得被新对话或外部工具悄悄覆盖。

`packet` 为每张图输出来自锁定合同的生成指令；Canva 变体仅允许排版，要求已有的画稿，明确禁止重新生成。恢复日志记录每次请求的合同摘要，保存摘要不一致的调用结果，但不把它们当作完成作品。已经导入的旧图仍可找回，不过在新合同下需重新核对视觉连续性才能成为最终已批准画稿。

合同独立于聊天记录；切换模型和供应商不会改变它。聊天文本或供应商返回的设计 ID 不能代替完整合同和原始图像文件。

## 备选方案

**只在聊天或 Canva 内维护连续性。** 不可取：上下文会被压缩，供应商返回结构和 ID 可能不稳定。

**把所有找到的图都当作批准的风格。** 不可取：概念草图与目标示例可能属于完全不同的作品。

**工具失败后重新生成全部页面。** 不可取：无效的 JSON 不代表原有文件已消失。

## 后果

Kira 在制作最终插画前必须加载并锁定创意合同。前期概念探索可以进行，但不能被当作最终成品。如果只有 Canva 生成能力而缺少实际画稿，必须告知阻碍而非虚构页面。哈希和文件检查只证明数据来源，不证明画面相似度或用户批准的真实性；艺术连续性依然需要编辑审核。该机制无法恢复未保存的聊天内容或已经丢失的图片。
