# Agent Note: 在普通任务中恢复经验并共享团队程序

Status: implemented

[English](2026-10-16-kira-shared-experience-ordinary-tasks.md) | 中文

## Problem

Phoenix 已有持久化的经验指标、子代理 token 归属、程序教学、经验证程序的自动检索及质量保护下的习惯提升。然而，经验汇总器过去主要在持久化的 `goal/change:complete` 事件发生时才记录成果，而许多普通聊天任务只产生 `turn/end`。此类任务中的失败、网站工具错误和团队操作序列因此可能无法指导下一次尝试。程序自动检索也使用全局最近任务指针，可能将其他并发聊天的任务错误注入当前任务。

## Decision

- 有工具活动的普通用户任务现在会保存有界的**未验证**性能记录。失败或中止的轮次增加诊断失败计数；普通轮次即使顺利结束也不能视为已验证成功。没有工具活动的闲聊不会产生此类经验记录。
- 记录仅包含端到端耗时、token 数、工具调用数、重试、人工介入与经过限制的失败工具**名称**，而不包含工具参数或表单内容。持久化读取器支持第一版数据格式，包括可选的有限失败名称和未验证标志。
- 没有正式目标的普通任务只把不含参数的工具调用序列保存为程序**候选**。只有通过验证的正式目标完成才能提升为可复用的有效程序或习惯。
- 子代理的工具调用与策略决策和资源消耗一样计入主代理的程序，子代理自身的完成不会结束主任务。所有任务上下文检索根据当前代理的所属会话选择，避免错误地使用其他聊天的最后一个提示。
- 相似的未验证尝试会生成有界诊断提示：注意曾失败的操作，并重新验证当前状态。记录学习本身不会产生额外模型调用或后台自我改进任务。

## Alternatives considered

**将普通模型轮次结束视为任务成功。** 这样可能奖励虚假的完成声明，并将失败的表单提交提升为习惯，形成有害正反馈。

**保存完整的浏览器或终端参数以便重放。** 虽然细节更多，但可能保存密码、个人答卷、令牌或过时选择器。因此只保留有限的操作名称及通过验证的通用程序。

**每次任务都从零规划。** 这会忽略已验证程序并浪费时间与 token；有界且按任务隔离的自动记忆更高效。

## Consequences

Kira 可跨重启识别重复工作，并记住之前的失败，包括普通任务；团队成员贡献共享的程序证据。未验证的历史不会作为成功习惯提升。学习器不会自行探索第三方网站的所有页面、编造问卷答案、绕过验证码或登录，也不会更改权限。实际速度仍需 Windows 浏览器基准与回归测试检验。

## Testing

经验测试覆盖未完成与被阻塞任务、失败工具名称留存、后续经验证的提升及无工具闲聊不生成记录。习惯测试覆盖未验证回忆只作为诊断提示。CI 检查 TypeScript 和仓库测试；真实网页试验验证实际延迟与质量。
