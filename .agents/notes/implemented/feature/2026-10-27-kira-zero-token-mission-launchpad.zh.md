# Agent Note: Kira 零 Token 任务启动入口

Status: implemented

[English](2026-10-27-kira-zero-token-mission-launchpad.md) | 中文

## Problem

Phoenix 已具备从用户资料读取姓名的欢迎界面以及经过验证的主动提醒，但空白对话缺少从意图进入具体任务的引导。启动时直接调用模型会浪费 Token，并可能在上下文不足时擅自操作。把某一用户的身份写死在公共界面中也不合适。

## Decision

空白对话欢迎区提供三个通用的西班牙语任务入口：继续、研究与构建。选择入口仅通过现有输入系统填写可编辑草稿，不会提交消息，也不会调用模型或工具。仅在已选择工作区、输入框未受阻、没有未发送草稿、也没有待处理主动提醒时显示入口。主动提醒始终优先。

实现复用已有的常驻输入框和资料感知欢迎界面；不新增持久化存储、设置格式、隐式提示注入、自动调度、权限变化或依赖。草稿要求以可核验的证据为准，不会宣称未经证实的完成状态。

## Alternatives considered

**打开 Phoenix 时自动启动任务。** 不采用：每次启动都有模型成本，并可能在用户未选定意图时修改项目。

**写死所有者身份和项目。** 不采用：界面供不同用户使用，个人资料应由用户管理。

**用独立的任务向导替换输入框。** 不采用：重复输入状态且可能丢失草稿。

## Consequences

Phoenix 以低干扰、零额外模型调用的入口帮助用户开始工作。任务由用户编辑后主动提交。此功能本身不赋予 Kira 自治权限；未执行实际任务时不能确认服务商、已有任务或项目权限是否可用。相关客户端回归测试覆盖草稿优先级、入口显示与不自动发送。
