# Agent Note：Game Studio 交付前的制作审核

Status: implemented

## Problem

生成器可能制作人物预设、首领图集、背景和音乐，却没有把它们连接到可玩的场景。清单和素材导入检查不能证明战斗、可到达的平台、关卡通关或音频播放正常。

## Decision

本地资源计划包含明确的制作审核：检查叙事连续性、角色行为、首领阶段与反制方式、关卡和跳跃范围、各关卡与首领配乐、运行时资源绑定以及独立游戏测试记录。工作流区分创意设计、可玩切片、资源制作、配乐、整合和游戏测试。模型提供的证据必须独立审查，因此报告不会自行认证游戏可以发布。解谜游戏不被强制要求战斗元素。

## Alternatives considered

**文件存在便表示资源完成。** 不采用，因为未使用的资源是核心故障。

**仅凭模型填写的检查框证明可玩。** 不采用，仍须观察实际执行、画面并聆听音频。

## Consequences

报告提供可复现的制作缺口和未绑定资源清单，便于 Kira 在大量生成昂贵素材前逐阶段修正。该审核不会自动绘画、安装 Godot、游玩游戏、验证证据文件内容或替代人工视觉和听觉评估。
