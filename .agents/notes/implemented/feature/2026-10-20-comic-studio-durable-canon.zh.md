# Agent Note：Comic Studio 的持久化角色设定与页面制作

Status: implemented

[English](2026-10-20-comic-studio-durable-canon.md) | 中文

## Problem

独立生成每一格漫画会改变角色外貌、丢失视觉参考，也可能与上一期剧情矛盾。单条提示词或一组图片文件无法可靠保存与恢复角色身份、剧情状态、阅读顺序及输出来源。

## Decision

`scripts/phoenix-comic-studio.mjs` 在 `~/.dsh/comic-studio/series/` 中持久保存每个系列。角色拥有稳定 ID、文字视觉特征、初始状态和不可直接替换的参考图片 ID。期数和编号页面保存有序画格、文字、图片 ID 及明确的前后状态变化。导入资源按 SHA-256 存储，同一逻辑 ID 不允许偷偷替换内容。审核在正式渲染前检查资源缺失或篡改、引用错误、重复画格 ID 和跨期剧情状态矛盾。HTML 将图片与对白分层，Chrome 可选地生成真正的 PDF 和逐页栅格化的 CBZ。Kira 可获取绘图简报并通过现有能力调用可用的图像供应商。

本地 CLI 是跨对话与临时任务运行环境的持久事实来源。创作技能调用该 CLI，而不是为漫画改写 Phoenix 通用代理循环。

## Alternatives considered

**每页只生成一张大图。** 不采用，因为角色及对白不可独立维护，修改单格容易破坏已确认的图片。

**只在聊天记录保存剧情。** 不采用，因为上下文会压缩、模型会变化，而且无法可靠追踪修订和视觉资源版本。

**将 SHA-256 一致当作角色长相一致的证明。** 不采用，因为文件完整性不能证明视觉相似、艺术质量和生成器遵守参考图。

## Consequences

此引擎提供可测试的持久设定和可独立导出的文件，但要求创建场景 JSON，并需要真实图像生成能力负责绘画。它不自带图像模型、视觉嵌入、外貌自动鉴别、商业封面与印刷出血制作、商店授权或版权许可。审核结果明确将视觉一致性、叙事质量、权利验证和印刷校样验证保留为未通过状态，正式交付仍需人工检查。目标环境尚未成功执行浏览器导出时，不可声称这些格式已经通过验证。
