# Agent Note: 先绘制首个草稿字符，再展开会话栏

Status: implemented

[English](2026-10-13-first-draft-paint-before-header-expansion.md) | 中文

## Problem

首个非空草稿同步展开隐藏的会话栏。这使会话列的几何布局与首个可见字符在同一次更新中变化，增加了输入路径上的布局工作。

## Decision

草稿编辑保持即时。自动展开栏等待一帧动画以及后续独立任务，让最初的草稿先绘制。就绪标记属于所选会话。清空草稿或切换会话会取消待执行的展开；显式固定仍然即时，视觉界面保留折叠栏的优先级。

## Alternatives considered

**延迟发布草稿。** 这会使受控输入本身更慢，并可能使装饰层不同步。

**取消自动展开。** 这会改变已批准的导航行为，而不是将其布局工作移出首次绘制。

## Consequences

开始输入后仍可使用相同的栏控件。此变更将同步展开栏移出首个字符更新；不能证明实测人的输入延迟改善，也不缩短模型或网络响应时间。

## Verification

组件回归在帧和任务展开前观察文本框与可见背景文字，并证明清空待处理草稿会取消过时操作。相邻骨架和栏样式测试保留手动固定、视觉焦点、常驻输入框身份以及复杂对话视图隔离。构建后应用的验收与单元证据分开。
