# Agent Note: Recover institutional research leads without retry loops

Status: implemented

[English](2026-10-28-research-search-resilience.md) | 中文

## Problem

免费 Bing 与 DuckDuckGo 搜索依赖固定的 HTML 属性顺序，并把 DuckDuckGo 重定向链接丢弃，导致无法恢复原始目标。关于学位论文、博士论文及参考文献要求的长问题也可能被归入通用研究分类。全部搜索失败时，研究工具仅抛出通用错误，没有保留失败查询数量，使智能体难以判断何时停止。

## Decision

HTML 提供程序独立解析结果链接，允许属性顺序变化与缺少摘要的结果；仅对来自 DuckDuckGo 的 `uddg` 重定向解析原始目标。研究计划将论文及研究生院规则归入学术分类，并在保留原始宽泛问题的同时缩短大学域名限定查询。研究工具过滤明显无关的学术结果，在提供程序不可用时返回明确的空结果及失败查询，并提示智能体停止等价的重复搜索，公开证据缺口。来源在阅读原始文件之前仍只是线索。

## Alternatives considered

**保留固定的 HTML 正则解析。** 放弃，因为摘要缺失或属性顺序改变可能隐藏真实的学术来源。

**把大学论文要求全部交给通用网页搜索。** 放弃，因为机构规则需要直接核对大学原始文件及限定范围的查询。

**无限尝试其他公开 HTML 搜索引擎。** 放弃，因为反机器人限制与被屏蔽的页面需要明确说明部分失败，而不是持续耗费时间和上下文。

**从搜索摘要推断参考文献数量。** 放弃，因为某个机构的规则并不等于所有学位的统一最低标准。

## Consequences

免费搜索仍依赖第三方 HTML，无法保证可用性。学术相关性过滤可能遗漏标题不明确但实际有效的页面，因此通用检索与直接访问大学网址仍是可用的替代方法。新的结果会明确暴露证据缺口而不编造引用，其他研究领域保持原有的有界查询行为。

## Testing

单元测试覆盖没有摘要的 HTML 结果、DuckDuckGo 重定向恢复、学术领域路由、无关结果过滤以及所有提供程序不可用的情况。
