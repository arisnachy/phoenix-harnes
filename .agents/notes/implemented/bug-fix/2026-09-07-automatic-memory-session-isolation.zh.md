# Agent Note: 自动记忆的会话隔离

Status: implemented

[English](2026-09-07-automatic-memory-session-isolation.md) | 中文

## Problem

自动提示组装在没有会话过滤的情况下读取共享旧版日志，因此无关项目的记忆可能进入同一个模型请求。目录名和最新创建的会话不能标识当前请求上下文的项目。

## Decision

消费者将正在组装请求的代理会话传给 `recallForSession()`。服务允许当前会话以及具有相同规范化绝对工作区路径的已加载会话，然后应用结果数量上限。路径缺失或为相对路径时，只允许当前会话。没有代理的诊断不接收自动记忆。显式认知搜索仍是独立操作。

## Verification

服务回归测试区分目录名相同的两个项目，保留同一目录内跨会话的连续性，隔离无项目会话，并在过滤后应用结果上限。消费者检查为真实代理组装上下文，并拒绝向诊断注入记忆。真实 Loader 快照在源码和构建模式下均通过，检查模型请求与持久化上下文，仅模拟外部模型适配器。

## Alternatives considered

- 按目录名过滤：无关路径可能同名。
- 使用最新的全局会话：并发请求可能属于不同项目。
- 每次组装都查询完整认知索引：改变检索成本，且不能确定当前请求会话。

## Consequences

无法取得会话头的历史记忆不会进入自动检索。路径别名和大小写不同的路径保持分离。不删除任何已存储记录，也不赋予记忆修改权限或工具的权力。显式认知搜索默认值和历史项目标识需要单独审查。
