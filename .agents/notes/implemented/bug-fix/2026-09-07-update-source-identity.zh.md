# Agent Note: 更新源身份

Status: implemented

[English](2026-09-07-update-source-identity.md) | 中文

## Problem

子字符串比较会接受带有额外仓库名称后缀的地址，以及包含预期 GitHub 路径的其他网站地址。这种匹配无法证明更新器使用了配置中指定的来源。

## Decision

源码预检、受管安装预检和已准备更新的激活共享同一个精确仓库匹配器。它接受 GitHub HTTPS 和 Git SSH 地址，检查主机及完整的所有者与仓库路径，并拒绝 HTTPS 地址中的凭据、查询字符串、片段及无关传输方式。仓库配置仍然是显式的。

## Verification

策略测试覆盖允许的传输方式和误导性地址。真实更新器进程在带有仿冒远程地址的一次性 Git 工作区中运行，并在获取或修改工作区之前拒绝该地址。相邻的状态、上游接收和已准备产物检查仍然是必需的。

## Alternatives considered

- 保留子字符串匹配：不能证明仓库身份。
- 只接受 HTTPS：排除了现有 GitHub SSH 安装。
- 在每个更新器中硬编码一个仓库：重复策略并阻止显式部署配置。

## Consequences

共享检查在各更新阶段一致地拒绝有歧义的远程地址。它确认来源身份，而不是候选代码的安全性；暂存验证和发布授权仍是独立要求。
