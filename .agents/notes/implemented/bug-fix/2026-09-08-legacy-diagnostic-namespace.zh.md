# Agent Note: 旧版诊断命名空间引用

Status: implemented

[English](2026-09-08-legacy-diagnostic-namespace.md) | 中文

## Problem

命名空间检查拒绝了 `doctor` 用于检测旧版安装的客户端模块字符串及其拒绝测试数据。这些字符串既不导入也不注册旧版包。

## Decision

仅允许所属路径下完全匹配的诊断行和测试数据行。这些文件中的其他引用仍受命名空间检查约束。检测器及其拒绝行为保持不变。

## Verification

定向扫描器回归测试必须接受这两行，并拒绝旧版导入、变更后的引用和不同上下文。仓库扫描仍是活跃引用的验收检查。

## Alternatives considered

- 排除诊断文件：允许无关的旧版导入。
- 在生产代码中通过字符串拼接隐藏旧名称：降低检测器的可审计性。
- 删除旧版检测：让过时的客户端引导程序通过诊断。

## Consequences

修改任一批准的诊断行都需要显式审查例外。此例外不授予运行时能力，也不允许旧版包依赖。
