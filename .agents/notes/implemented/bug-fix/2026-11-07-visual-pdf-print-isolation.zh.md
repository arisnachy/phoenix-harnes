# Agent Note: 独立的专业 PDF 打印与容器自适应界面

Status: implemented

## Problem

PHOENIX Visual Intelligence 的“Imprimir / PDF”原来在整个浏览器页面上调用 `window.print()`。用户在 2026-11-07 的截图显示打印预览包含应用侧栏、会话、输入框及无关控件，而不是单独的专业报告。其他智能界面主要依赖窗口大小，但聊天气泡即使在宽屏中也可能很窄。

## Decision

使用 `VisualIntelligencePdf.ts` 本地生成独立、确定性的 PDF，取代整个网页打印。报告直接从**经过验证的结构化数据**生成，不截取 DOM、HTML canvas 或聊天画面。内容包括专业标题、数据追溯、指标卡、矢量图、完整且可分页的表格、文档正文、地点坐标、媒体引用、来源及限制。多列数据转换为可读的记录卡，避免页面截断。

“Imprimir informe”在单独标签页打开生成的 PDF，由浏览器 PDF 阅读器只打印该文档。“Descargar PDF profesional”下载完全相同的 PDF。文档编辑器也使用该生成流程并保留实际编辑内容。仅在同源服务实际返回数据时导出带时间的实时快照；否则明确标注暂无实时数据。临床评估继续使用独立的严格报告工具，不会将空白表单当作已经完成的患者问卷。

使用 CSS 容器查询，让 `visual_intelligence`、通用画布、智能卡和表单适应**组件自身的宽度**，而非仅靠浏览器窗口宽度。窄聊天窗中的表格可横向滚动，PDF 仍导出全部行而非当前可见部分。

## Alternatives considered

**全屏打印并用全局 CSS 隐藏侧栏。** 拒绝，因为复杂客户端的其他打印样式、iframe 和滚动位置会导致内容泄露或错位。

**截图或将 HTML 转成位图。** 拒绝，因为容易截断、像素化、不可搜索，也可能泄露周围的聊天信息。

**超出一页就截断数据。** 拒绝，要求完整分页。

## Consequences

报告以可搜索文字和矢量图为主，不依赖聊天 UI。远程图片及交互式地图不作为位图嵌入，只提供来源信息与坐标，避免追踪和伪造。生成 PDF 不证明模型提供的临床或科学事实正确。打印系统调用由浏览器的独立 PDF 阅读器处理。测试覆盖内容、分页、安全文本转义、实时信息及按钮行为，CI 检查编译和回归。
