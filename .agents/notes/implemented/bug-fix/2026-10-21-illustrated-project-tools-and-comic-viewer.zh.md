# Agent Note: 插图项目工具与嵌套漫画查看器

Status: implemented

[English](2026-10-21-illustrated-project-tools-and-comic-viewer.md) | 中文

## Problem

恢复漫画的请求提及生成插图，触发了独立图像偏好，隐藏了文件、组装和发布工具。成功的图像调用仍将该限制保留到空闲状态。另外，漫画发布器缺少嵌套展示元数据，导致 Code Mode 可以报告发布成功，却未向客户端交付阅读器制品。

## Decision

插图项目保留完整的许可工具目录；独立图像请求在首次尝试结束前保留原生图像优先级。新的用户指令会替换该偏好。漫画发布器选择保留持久化的嵌套制品元数据，与地图发布器一致。现有结构检查、工作区限制和静态 iframe 权限继续生效。

漫画制品还提供现有的展开阅读控件，并以 `.html` 扩展名下载包含静态内容安全策略的自包含 HTML，避免仅因在 iframe 外打开保存版本就执行行内事件处理程序。普通应用 HTML 保留现有的行内展示方式。

## Consequences

智能体可以在生成缺失插图前检查和恢复项目，集成成功生成的图像，并从 Code Mode 发布阅读器制品。无需密钥的浏览器场景执行真实 worker 与发布器，持久化其结果，并使用明确标注的合成插图和地理数据打开漫画与地图查看器。该场景不认证艺术质量或远程图像服务。

## Alternatives considered

增加提示指令无法恢复隐藏工具或缺失的制品元数据。完全删除原生图像偏好会丢失独立图像路由。替换现有查看器无法修复这两个根因。
