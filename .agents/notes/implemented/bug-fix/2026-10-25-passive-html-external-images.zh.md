# Agent Note: 无脚本权限的静态 HTML 图片加载

Status: implemented

[English](2026-10-25-passive-html-external-images.md) | 中文

## Problem

生成的首页和报告经常引用外部照片，却不包含 JavaScript。工件渲染器把所有标记为可执行的 HTML 都视为可运行脚本的应用，因此默认的图片内容安全策略会阻止照片加载，只显示替代文字。相同的查看器切换到另一份 HTML 时，先前的图片联网许可也可能继续生效。

## Decision

当 HTML 不包含 script 标签、内联事件处理器或 JavaScript URL 时，对话工件渲染器使用禁止脚本的同源沙箱；这类文档可以加载远程图片，但不能执行作者脚本。包含可执行结构的 HTML 与 Game Studio 预览继续使用不透明来源的脚本沙箱，并需要用户明确授权才可加载远程图片。图片联网许可仅适用于当前查看器所展示的确切 HTML 内容，不会自动授予另一份内容。许可检测同样识别省略协议的远程图片地址。

## Alternatives considered

**默认允许所有可执行工件加载远程图片。** 即使 `connect-src` 被禁止，脚本创建的图片请求仍可能传出信息，所以自动授权会削弱已有隔离。

**所有静态首页都要求图片联网许可。** 这会让普通无脚本 HTML 预览在禁止脚本执行的前提下仍显示不完整。

## Consequences

无脚本页面可以显示照片，同时保留 Phoenix 的脚本限制。含 JavaScript 的页面保留交互能力，但加载图片需要明确操作；第三方图片服务器仍可能拒绝外链或返回无效地址。组件测试覆盖两种路径，并检查许可不会随 HTML 内容切换而沿用。
