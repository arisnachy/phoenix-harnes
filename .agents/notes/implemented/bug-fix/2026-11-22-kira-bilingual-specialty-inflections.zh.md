# Agent Note：Kira 专家分派识别自然西班牙语词形

状态：已实现

[English](2026-11-22-kira-bilingual-specialty-inflections.md) | 中文

## 问题

Kira 为未指定成员姓名的任务按职责文本选择专长池。现有正则表达式中的部分词干后紧跟词边界，使 `investigación`、`automatización`、`optimización` 和 `auditoría` 等常见西班牙语词形无法匹配。即使存在合适专家，任务也可能错误地落入通用池。

## 决策

在现有部分西语、英语词干后允许零个或多个 Unicode 字母，保留已存在的确定性优先级与专家池。不增加新成员、模型路由权限、提供方或提示词预算。

## 局限

词汇匹配仍是启发式规则。模糊任务可能同时命中多个类别，此时沿用现有优先级。本变更并非按实际表现选择模型，也不是基于大模型的语义分类或经实测的智能基准提升。

## 验证

用自然西班牙语任务表覆盖研究、自动化、性能优化、质量审核、文稿、设计、统计、安全和工程，验证公开的专长分类与成员选择函数。实际模型表现和用户成果仍需独立评估。
