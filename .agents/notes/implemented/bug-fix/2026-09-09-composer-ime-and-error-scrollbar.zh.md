# Agent Note：输入法与错误滚动条修复

状态：已实现

[English](2026-09-09-composer-ime-and-error-scrollbar.md) | 中文

## 问题

某些 Windows 输入法只通过旧式原生键码 `229` 报告正在组合输入。在这种状态下按 Enter 会推进问题流程。抬升错误表面内的原始 JSON 还会继承页面级滚动条颜色，导致对比度不足。

## 决策

问题输入组件除标准组合信号外，也识别原生键码 `229`。此时 Enter 只确认输入候选，不改变问题状态。原始 JSON 表面把滚动条令牌绑定到该面板已使用的抬升级调色板。

## Alternatives considered

**只使用标准 composition flag：**拒绝，因为受影响的 Windows browser 与 IME 组合不会可靠设置该标志。

**修改全局滚动条颜色：**拒绝，因为对比度缺陷属于抬升错误表面，全局修改会改变无关 UI。

## 验证

聚焦客户端与组装回归选择共 168 项测试通过。问题包 README 记录组合输入行为，会话 README 记录抬升滚动条行为。

## 结果

Windows 输入法用户确认候选时会留在当前问题。结构化错误详情在现有 PHOENIX 主题中保持可读。
