# Agent Note: 安全的 Computer 学习

状态：已实现

[English](2026-09-23-safe-computer-learning.md) | 中文

## 问题

Computer 结果只能说明操作系统接受了动作，并不能证明用户的应用目标已经成功；原始 Computer 参数还可能包含凭据或私有表单数据。

## 决策

session-learning 插件会立即把 Computer 调用投影为封闭的浏览器动作名称和规范化 HTTPS 来源。它不会保存原始参数、结果、文本、坐标、路径、截图或字段值。失败、清除、错误通过、无效输入或未完成工具调用都会丢弃轨迹。只有携带完成状态的持久化 `goal/change` 事件才会把有界轨迹提升为认知记忆。同一项目中重复验证的目标可以产生枚举偏好。

`computer_learning` 只公开安全的 review 字段，并提供需要精确 ID 的显式 forget 操作。遗忘会写入认知日志墓碑，因此审计历史仍然存在，同时记录会从活动回忆中消失。投影流程只是证据，不会改变权限、审批或工具能力。

## 考虑过的替代方案

**在操作系统接受 Computer 动作后就学习。** 不采用，因为这不能验证用户目标，还可能保留私有表单值。

**保存完整 Computer 参数和结果以供稍后重放。** 不采用，因为这些记录可能包含凭据、个人数据或临时页面状态。

**模型声称成功后提升流程。** 不采用，因为模型文本不是持久化证据；提升必须等待匹配的持久化目标完成事件。

## 结果

Computer 学习通过现有认知日志跨重启保存，不创建第二个轨迹存储。通用过程观察器忽略 Computer 调用，避免原始桌面动作进入另一条学习路径。候选和格式错误的 Computer 记录会从自动搜索中排除。该功能依赖目标服务的持久化完成事件；单独接受工具结果不会创建活动记忆。
