# Agent Note：在认知记忆层之间保留规范事件

Status: implemented

[English](2026-09-01-cognitive-memory-layers.md) | 中文

## 问题

学习记忆以前只在一个有界日志中保存部分用户、工具、回合和错误观察结果。保留上限可能把旧记录标记为遗忘，自动检索没有项目隔离，不可信记忆文本还可能包含提示变量分隔符。

## 决策

`dsh-session-learning` 保留会话事件日志作为自传式记忆的规范归档，并写入相邻的 `.cognitive.jsonl` 追加式索引。每个持久会话事件都会生成脱敏记录，并包含工作、情景、时间层，以及由事件推导的语义、程序、前瞻或联想层。记录保留来源会话、事件序号、事件类型、项目、来源 URI、实体、关系、有效时间、置信度、重要性、频率和生命周期状态。

语义记录通过强化巩固相同观察结果，通过带有效时间的 `superseded` 记录保留变化值。显式遗忘只写入墓碑；旧版兼容上限和认知检索都不会压缩或删除规范记录。认知检索结合归一化词法、确定性别名、实体、关系、项目和时间过滤、重要性、置信度、频率及新近度。自动上下文使用当前项目，并在提示组装前中和不可信记忆值中的 `{{` 和 `}}`。

## 结果

重启学习服务会从持久行重载两个日志并重建派生索引。新模型或上下文摘要不能擦除来源事件。被替代事实仍可通过时间线和历史查询访问，显式遗忘记录可通过 `allCognitiveRecords()` 审计但不会返回给模型。排序器是确定性的，不宣称等同于向量语义检索。

## 考虑过的替代方案

**用认知索引替换规范会话日志**被否决，因为派生索引可以重建，不能成为事件的唯一副本。**将旧记忆压缩成摘要**被否决，因为这会丢失来源和历史矛盾。**只使用嵌入进行检索**被否决，因为可审计的召回和可预测的隔离需要确定性的项目、时间、实体、关系和词法过滤。

## 验证

认知、旧版日志、服务和展示聚焦测试一起通过。工作区 `typecheck` 也通过，包括 Host 构建和 contract-ready Client 类型检查。原始会话持久化和多模型实时记忆行为仍由现有运行时和 e2e 门禁管理。
