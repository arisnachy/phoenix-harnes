# 2026-11-06 — APEX expert research contract

## Intent
Improve research completeness and professional presentation without replacing
the governed search provider or adding a heavyweight second orchestration loop.

## Observed seams
\`research_investigate\` already tracks readable results, source ownership,
duplicate hashes and blocked providers; \`cognitive-workflow\` already selects
cost-sensitive processes for all mission types. These are the correct integration
points. Evidence status remains \`retrieved_unverified\`.

## Change
Provide an explicit professional output contract generated deterministically
from routed discipline and observed retrieval receipts. Add opt-in bounded
\`expert\` acquisition depth; preserve existing ordinary search latency.
HARDNESS carries universal output guidance, not a claim that any model has
human professional credentials. Visuals require actual data or real image
provenance and must not block textual content.

## Risks and tests
Targeted unit tests cover cross-domain routing, dose-specific context,
source independence, blocked sources and visual constraints. Review provider
timeouts, source-cap boundaries and snapshot behavior. Full CI and Windows
gates require real execution before declaring the work production-ready.
