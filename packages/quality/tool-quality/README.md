# @phoenix-ai/dsh-tool-quality

Model-facing controls for PHOENIX quality and foresight assessments.

The plugin exposes `quality_get` and `quality_record` over `ctx.quality` and contributes a standing policy for substantial and living work: derive acceptance criteria, challenge relevant edge cases, label evidence truthfully as static/simulated/live, keep forecasts explicitly hypothetical until confirmed, repair material findings, and evaluate one bounded innovation only after the requested work is complete.

The plugin records evidence only. It does not create a second continuation loop, broaden permissions, control living creations, or promote predictions into verified learning.
