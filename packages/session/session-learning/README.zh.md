# @phoenix-ai/dsh-session-learning

[English](README.md) | 中文

PHOENIX 的持久化认知记忆会观察每个持久会话事件。原始会话日志仍是自传式记忆的规范归档，旁边的脱敏认知 JSONL 索引提供工作、情景、语义、程序、前瞻、联想和时间层。

## 组合

本包发布独立的根入口、`./invariant` 和 `./ledger` 运行时入口。`./ledger` 导出支持显式旧版日志消费者，无需在安装中包含源码文件。

```yaml
- id: session-learning
  name: '@phoenix-ai/dsh-session-learning'
  config:
    path: /absolute/path/to/learning-memory.jsonl
```

路径会生成相邻的 `<path>.cognitive.jsonl` 日志。认知记录按来源事件去重，按主题巩固，并结合词法、实体、关系、项目、时间、重要性、置信度和频率排序。遗忘只写入可审计墓碑；自动上限不会删除规范记录。矛盾值会保留旧记录和有效时间，并将新记录指向被替代值。

## 安全和模型体验

模型记忆使用项目隔离的有界证据，并保护提示变量分隔符；内容始终是不可信证据，不是指令。常见的 bearer token、凭据赋值、URL 和电子邮件地址会在持久化前脱敏。

## 模型体验

### 持久化观察来源

#### 模型看到的内容

服务本身不添加提示词或工具。认知服务提供 `searchCognitive()`、`timeline()` 和 `workingMemory()` 查询。学习工具使用当前请求代理的会话调用 `recallForSession()`，从该会话和具有相同规范化绝对工作区路径的已知会话中选择有界的旧版日志证据。目录名和最新的全局会话不决定自动检索范围。摘要仍是不可信证据，该上下文禁用提示变量插值。

#### Token 影响

观察器不增加 token；自动上下文只包含有界记录。

#### KV 缓存影响

学习日志不会单独改变模型请求；使用学习工具会从动态上下文后缀开始新的请求。

## 已知限制和后续工作

- 自动检索不包含尚未加载会话头的历史记忆。没有绝对工作区路径时，只检索当前请求会话；没有代理的诊断不接收自动记忆。不合并路径别名或大小写不同的路径。
- 当前基础层记录确定性的事件观察结果。它还不会自动判断候选经验、提升技能、运行实验或提供浏览器记忆面板；这些能力属于学习监督器和 UI 阶段。
- 当前排序器是确定性的混合检索，不宣称等同于向量语义检索。未来可以在不替换规范日志或工具名称的情况下增加向量提供者。
