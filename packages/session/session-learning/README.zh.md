# @phoenix-ai/dsh-session-learning

[English](README.md) | 中文

此包为 PHOENIX 提供持久化、带来源信息的学习记忆。它观察持久化会话事件，并将有界的交互、成功、错误和持久用户偏好记录写入仅限用户访问的追加式 JSONL 日志。学习工具还会把最近的非交互记录作为有界的不可信上下文提供给模型。

## 组合

```yaml
- id: session-learning
  name: '@phoenix-ai/dsh-session-learning'
  config:
    path: /absolute/path/to/learning-memory.jsonl
```

路径必须明确，因为学习记录可能包含用户提供的文本。服务需要 `sessions`，提供 `ctx.learningMemory`，并按会话、事件序号和类别去重记录。

## 安全和模型体验

日志不会静默修改权限、凭据或受信任插件。对于「这很重要」「记住这个」「始终」和「我更喜欢」等明确的保留信号，系统会自动提升为高置信度偏好记忆；普通交互仍作为较低置信度历史保存。组合的学习工具会优先提供高置信度的持久偏好、课程与技能，再补充最近的非交互记录，组成有界不可信上下文；原始交互必须显式使用 `memory_search`。摘要有长度限制，并在持久化前删除常见的密钥赋值。

## 模型体验

### 持久化观察来源

#### 模型看到的内容

服务本身不增加提示词或工具模式。学习工具消费者在组装期间读取 `recent()`，提供有界的非交互上下文，并将其作为不可信证据而不是指令。

#### Token 影响

观察器不增加 token；自动上下文只包含有界记录。

#### KV 缓存影响

学习日志不会单独改变模型请求；使用学习工具会从动态上下文后缀开始新的请求。

## 已知限制和后续工作

- 当前基础层记录确定性的事件观察结果。它还不会自动判断候选经验、提升技能、运行实验或提供浏览器记忆面板；这些能力属于学习监督器和 UI 阶段。
