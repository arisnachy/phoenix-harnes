# @phoenix-ai/dsh-tool-image-generation-codex

由官方 Codex 子代理提供支持的 Phoenix 模型侧图像生成工具。

插件仅在配置的子代理提供方（默认 `codex`）可用时注册 `image_generation`。每次调用都会在发起 Agent 的工作区中创建一个由 Phoenix 管理的目录，要求 Codex 使用其内置图像生成能力，只接受一个栅格图像和一个受限 JSON 清单；随后先释放 Codex 运行，再验证文件系统结果，并通过 `ctx.attachments.saveImage()` 提交图像字节。

## 安全与生命周期

生成路径必须位于 `.phoenix/generated-images/<call>/` 内。清单只能命名一个基本文件名，声明的媒体类型必须与扩展名一致。路径穿越、符号链接、非普通文件、意外文件、多个栅格图像、不支持的媒体类型、超出大小限制、Codex 异常终止、附件拒绝，以及缺少 Agent/工作区上下文都会失败关闭。失败调用不会发布附件，并会删除该调用拥有的输出目录。

`ctx.attachments.saveImage()` 是发布边界。工具不会向模型暴露主机绝对路径或任意外部 URL。成功调用保留工作区文件，并返回 Phoenix 历史记录与重放所使用的持久、标准化 `ImageAttachmentRef`。

## 模型体验

默认的模型侧工具名为 `image_generation`，输入为一个详细的 `prompt`。成功时会把生成图像渲染为普通 Phoenix 图像内容块，并附带简洁的工作区相对路径，因此调用方可以继续在网页、演示文稿、报告或其他交付物中使用该视觉资源。

随产品提供的 standard KIRA 预设会在原创视觉能实质提升交付质量时使用此工具。该工具不会静默回退到其他图像提供方或 API-key 路由。

## 已知限制

第一版只支持文本生成图像，并且每次调用只发布一个栅格图像。图像编辑、遮罩、多输出、任意文件生成和提供方回退均刻意不属于本包范围。可用性还取决于当前已安装的 Codex 运行时是否为已认证用户/会话提供其内置图像生成能力。
