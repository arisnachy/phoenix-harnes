# @phoenix-ai/dsh-client-ui-settings-profile

[English](README.md) | 中文

本地用户资料的浏览器设置行。它会在点击保存前将草稿保留在本地，提供通用资料字段和家庭成员条目，并要求逐项同意后，宿主端资料服务才能将字段投影到模型上下文。首次收到宿主端持久化资料时，会先完成 hydration 再判断 dirty 状态，因此重新打开设置会立即显示已保存值；之后的宿主刷新仍会保留真正编辑中的本地草稿。

该行还可以编辑 KIRA 的助手名称以及男性化、女性化或中性的呈现。模型设置页面通过相邻箭头负责编辑提供方顺序；顺序保存在同一本地偏好命名空间中，因此对话模型选择器会从宿主端收到它。

## 模型体验

### 资料设置行

#### 模型看到的内容

该浏览器端插件的任何内容都不会进入模型请求；`UserProfileService` 负责按同意过滤的模型上下文。

#### Token 影响

该包只渲染资料设置并在浏览器中保留未保存的草稿，因此不会增加模型 Token。

#### KV Cache 影响

该包不组装也不发送提供方请求，因此不会影响提供方前缀复用。

## 已知限制与暂缓事项

- 该行需要可写的宿主设置 scope；只读部署可以显示状态，但不能保存资料变更。
