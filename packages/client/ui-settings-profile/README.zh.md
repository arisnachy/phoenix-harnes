# @deepseek-ai/dsh-client-ui-settings-profile

[English](README.md) | 中文

本地用户资料的浏览器设置行。它会在点击保存前将草稿保留在本地，提供通用资料字段和家庭成员条目，并要求逐项同意后，宿主端资料服务才能将字段投影到模型上下文。

## 模型体验

### 资料设置行

#### 模型看到的内容

该浏览器端插件的任何内容都不会进入模型请求；`UserProfileService` 负责按同意过滤的模型上下文。

#### Token 影响

该包只渲染资料设置并在浏览器中保留未保存的草稿，因此不会增加模型 Token。

#### KV Cache 影响

该包不组装也不发送提供方请求，因此不会影响提供方前缀复用。

## 已知限制与暂缓事项

- 该行需要可写的宿主设置 scope；只读部署可以显示状态，但不能保存资料变更。
