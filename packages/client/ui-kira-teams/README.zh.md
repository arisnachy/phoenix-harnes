# @phoenix-ai/dsh-client-ui-kira-teams

[English](README.md) | 中文

当前会话中活动 KIRA 子代理的浏览器停靠面板。它将宿主端维护的 roster 投影为可刷新面板，已结束的子代理会从可见团队中移除，并在任务标签旁显示活动代理的模型名称。

## 模型体验

### 团队停靠状态

#### 模型看到的内容

该浏览器端插件的任何内容都不会进入模型请求；停靠面板只为用户渲染宿主端发布的 `KIRA` 团队状态。

#### Token 影响

该包不注册提示词、工具或请求字段，因此不会增加模型 Token。

#### KV Cache 影响

该包不组装也不发送提供方请求，因此不会影响提供方前缀复用。

## 已知限制与暂缓事项

- 停靠面板只能显示当前宿主会话发布的活动子代理；已结束、远程或历史团队不会显示。
