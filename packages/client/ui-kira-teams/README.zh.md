# @phoenix-ai/dsh-client-ui-kira-teams

[English](README.md) | 中文

当前会话中活跃 KIRA 子代理的浏览器任务控制覆盖层。固定高度的活动条显示当前选中的代理以及模型真实生成的活动文本，并且不会因为团队人数增加而变高：活动条最多叠放三个头像，其余代理合并为 `+N` 计数。右侧的窄代理轨道始终保留每个活跃代理的直接选择入口；只有用户主动展开时，活动条下方才显示扁平的详细列表。

该覆盖层不会占用会话区域宽度。选择头像会切换活动条当前显示的代理；激活活动条中的当前代理会在现有主会话中突出显示该代理的发言。已结束或空闲的子代理会从活动条和代理轨道中移除。

## 主会话

真实子代理输出在主会话中使用持久化的名称、头像和职责。消息操作提供分组的 Unicode 表情、可搜索的原生表情选择器以及用户自身表情的移除。回复在现有输入框上方选择引用上下文；`@Name` 或 `@"Name with spaces"` 可指向一个或多个已有的可继续代理。保留请求身份可避免 RPC 响应丢失后重复接收消息，重新连接会重试待发送请求。原始消息行会显示待发送状态。一次性子代理的历史仍可阅读，但不能通过这些回复恢复。
## 模型体验

### 团队活动状态

#### 模型看到什么

这个仅浏览器使用的插件不会向模型请求加入任何内容；覆盖层只向用户渲染主机发布的 `KIRA` 团队状态。

#### Token 影响

该包不注册提示词、工具或请求字段，因此不会增加模型 token。

#### KV Cache 影响

该包不会组装或发送供应商请求，因此不会影响供应商前缀复用。

## 已知限制与后续工作

- 代理轨道只能显示当前主机会话发布的活跃子代理；已结束、远程或历史团队不会显示。

普通用户 fork 中继承的团队消息仍可阅读。另一任务的操作控件被禁用；新的回复和反应仍由当前任务拥有。
