# @phoenix-ai/dsh-client-ui-kira-teams

[English](README.md) | 中文

当前会话中已部署 KIRA 子代理的浏览器停靠面板。它将宿主端维护的 roster 投影为可刷新面板，并在对话旁显示每个团队的运行或完成状态。

## 模型体验

### 团队停靠状态

#### 模型看到的内容

该浏览器端插件的任何内容都不会进入模型请求；停靠面板只为用户渲染宿主端发布的 `KIRA` 团队状态。

#### Token 影响

该包不注册提示词、工具或请求字段，因此不会增加模型 Token。

#### KV Cache 影响

该包不组装也不发送提供方请求，因此不会影响提供方前缀复用。

## 已知限制与暂缓事项

- 停靠面板只能显示当前宿主会话发布的子代理，不包含远程或历史团队。
