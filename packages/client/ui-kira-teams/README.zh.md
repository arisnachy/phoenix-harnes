# @phoenix-ai/dsh-client-ui-kira-teams

[English](README.md) | 中文

当前会话中活跃 KIRA 子代理的浏览器任务控制覆盖层。固定高度的活动条显示当前选中的代理以及模型真实生成的活动文本，并且不会因为团队人数增加而变高：活动条最多叠放三个头像，其余代理合并为 `+N` 计数。右侧的窄代理轨道始终保留每个活跃代理的直接选择入口；只有用户主动展开时，活动条下方才显示扁平的详细列表。

该覆盖层不会占用会话区域宽度。选择头像会切换活动条当前显示的代理；激活活动条中的当前代理会打开对应的可继续子代理会话。已结束或空闲的子代理会从活动条和代理轨道中移除。

## 模型体验

### 团队活动状态

#### 模型看到什么

这个仅浏览器使用的插件不会向模型请求加入任何内容；覆盖层只向用户渲染主机发布的 `KIRA` 团队状态。

#### Token 影响

该包不注册提示词、工具或请求字段，因此不会增加模型 token。

#### KV Cache 影响

该包不会组装或发送供应商请求，因此不会影响供应商前缀复用。

## 已知限制与后续工作

- 代理轨道只能显示当前主机会话发布的活跃子代理；已结束、远程或历史团队不会显示。
