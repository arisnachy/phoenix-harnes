# @phoenix-ai/dsh-user-profile

[English](README.md) | 中文

带有逐字段同意控制的本地资料设置。该服务验证有界字段，只持久化用户提供的值，并分别提供用于诊断的副本和用于模型上下文的同意过滤投影。

同一命名空间还保存助手身份，默认名称为 `KIRA`，默认使用中性呈现。身份通过专用系统提示词上下文对模型可见，并要求采用自然、温暖的对话方式，在合适时使用克制的情境幽默、俏皮表达和温和讽刺，但不得声称助手是人类。记忆回答必须以证据为准：年龄、诊断、关系、偏好或事件等属性只能归属于资料、记忆或会话证据明确支持的具体人物、项目或实体；证据不足、过时、矛盾或可信度低时必须明确说明，而不能用推断补空。该命名空间还保存可选的提供方路由顺序；该偏好只改变显示顺序，绝不会成为路由允许列表。

## 模型体验

### 已同意的用户资料上下文

#### 模型看到的内容

至少启用一个同意标志时，系统提示词会收到 `User-provided profile context` 区块，其中只包含获准的首选称呼、计算出的年龄、性别、代词、语气和家庭条目。

#### Token 影响

资料区块只将已同意的值加入每个组装请求；空的同意投影不会加入资料文本。

#### KV Cache 影响

同意投影不变时，动态资料区块保持稳定；保存获准的值会替换该上下文，可能使下一次请求无法复用此前缀。

**PHOENIX Moments（用户授权后启用）**

用户资料可以保存 ISO 两位国家代码 `countryCode`，以及可选 IANA 时区`momentsTimeZone` 以及最多 100 个个人日期 `specialDates`（`MM-DD` 或 `YYYY-MM-DD`，名称，可选庄重标记）。默认关闭；只有 `consent.moments` 开启后才会向模型传递当天的重要日期。用户生日还需要独立允许 `consent.dateOfBirth`。关闭功能立即停止提供日期上下文，但不会删除用户自行保存的数据。

公开节假日来自 Nager.Date。查询仅发送国家代码和年份，不发送私人资料。请求失败时使用少量多米尼加爱国节日和全球节庆的本地备用信息。它不是覆盖世界上所有地方、宗教与文化日期的完整数据库。

Kira 仅在当天匹配时接收最多八条简短事实。不会自动发送问候，也不使用固定祝福语。启用授权后，西班牙语对话中明确提供的家庭生日或纪念日可以保存为年度日期，并可在个人资料中修改或删除。浏览器会显示小型、不会干扰工作或改变基础主题的节庆装饰。本次尚未接入 Google Calendar 等私人日历账户。

## 已知限制与暂缓事项

- 资料数据属于配置的设置提供方；该包不会在设备或账户之间同步资料。
