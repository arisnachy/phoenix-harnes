# `@phoenix-ai/dsh-tool-business`

[English](README.md) | 中文

面向模型的**只读**商业任务规划器。Kira 可以识别图书、课程、软件、游戏、设计、研究、视频、音频和商业服务，并检查当前 MCP 运行时目录，且不会获取凭据。本工具**不创建商品、不执行发布，也不花费资金**。

## Model Experience

### 商业任务规划

#### What the model sees

`business_plan_mission` 接收用户的原始商业请求，返回推断的产品类别、用户要求的动作、可能的销售渠道、相关 MCP 工具候选项、授权阻碍以及下一步安全动作。每次调用都会重新查询运行时目录。`ready` 只代表连接状态，**不**证明工具已通过审计、当前账户具有写入权限或用户已同意公开操作。目录缺失时报告为不可用，而不是认定不存在集成。像「no publiques」（不要发布）这样的否定命令优先于普通发布关键词。

#### Token effect

简短、稳定的常设规则引导商业任务按需调用一次规划器。只有收到请求时才返回 MCP 目录投影，不会在每条系统提示中序列化连接器信息。用户意图和运行时状态未变时，避免重复调用。

#### KV Cache effect

工具 schema 与常设指令在请求间保持稳定。运行时工具名称与任务特有意图仅按需返回到对话尾部，保留可复用的提示前缀。

## Known Limitations and Deferred Work

- 规划并非执行。本包不会分发 MCP 调用，也不会打开内嵌浏览器会话。
- 根据工具名称匹配仅能提供候选建议，不能证明真实性、细粒度权限、合规性或商店可用性。
- 类别识别采用启发式规则；模糊或冲突的指令需要语义复核，且仅在必要时询问。
- 商品生产、编辑质量、许可证检查、商店写入、数字交付、支付处理、税务、已确认收据以及销售对账，均需要独立可信服务。
- Shopify 草稿支持是独立模块 `scripts/phoenix-business-shopify.mjs`，需要凭据和由 Host 核实的批准；它没有安装为可自主调用的模型工具。
- **不支持**通过此规划器实现完全自动上线。在正式上线前仍需使用已认证的商家账户做集成测试，并核查平台特定规则。
