# PHOENIX ORÁCULO · 科学预测核心

模型可以调用三个本地工具：oracle_scientific_forecast、oracle_audit_prediction 和 oracle_forecast_scorecard。物理模型受假设限制；时间序列使用按时间顺序的回测；线性因果图的参数由调用方提供，**不是**从数据识别出的因果关系。

## Model Experience

只有具备数据与来源信息时才预测。未来事件并不总是可精确推算。预测结果、假设、名义区间以及结果记录可供审查。来源由调用方提供，不代表系统已核实。结果审核同样只是未核实的报告。

## Known Limitations

没有实时世界数据连接、独立的前瞻验证、通用世界模型或保证准确率。不要输入患者身份信息、密码或机密。预测数据保存在本地 PHOENIX 主目录，不在临时运行目录。
