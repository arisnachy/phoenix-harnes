# Phoenix Universal — 按任务意图显示能力，而不是固定模块

**状态：**已修复通用首页，建立产品约束。

## 全局不变量

Phoenix 是通用工作环境，不是专门的科研、游戏、医疗、商务或社交软件。
安装任何工具或连接器，不应自动在首页增加一个固定按钮。
首页只保留身份、问候、通用输入框、工作区和真实任务提醒。

## 上下文呈现

1. 用户使用自然语言提出任意任务。
2. Kira 判断意图、上下文、限制以及实际可用的工具和权限。
3. 通过通用工具注册表选择能力，不要求用户先选领域。
4. 只有任务真正需要时才在当前会话中呈现专用表单、封面编辑器、
   3D 视图、浏览器或图表。
5. 更换任务后自动收起临时界面；用户也可明确要求打开。

专用界面不能成为永久菜单，也不能重复已有输入框。
它应复用用户已提供的信息，仅询问真正缺少的字段。

## 验收规则

- 全局 Hero 不得包含 onResearchSelect、onGameSelect 等领域专用回调。
- 删除首页学术按钮，不影响 Kira 通过自然语言调用科研工具。
- 新增任何能力不应修改通用首页，除非改善其通用功能。
- 连接器安装、授权、执行和被阻止的状态必须如实显示。
- 任意领域的界面应由任务上下文触发，而非固定领域列表。

## 后续扩展点

真正的通用上下文界面需来自任务或工具注册表中的显示契约，
而不是预置领域快捷方式。研究专用封面编辑器不能挂在通用首页。
在通用任务展示契约完成前，Kira 仍可使用已有科研工具聊天完成任务。

本修复只清除了领域专用首页元素；不虚称已完成整个上下文展示引擎。
