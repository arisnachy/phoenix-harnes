# 免费网页研究回退

[English](2026-08-26-web-search-free-fallback-design.md) | 中文

## 目标

避免主要提供商的额度、配额、认证、限制或可用性故障终止研究。PHOENIX 应尝试通过专用浏览器走可验证的免费路线；如果不可用，则尝试免费的 HTTP 路线。

## 范围

仅修改网页搜索能力。不修改身份、凭据、核心 prompt、全局 sandbox 或付费提供商。主要提供商可用时仍保持最高优先级。

## 设计

`ctx.web.search()` 将使用显式回退策略。它先执行已配置提供商。可恢复错误会在不暴露秘密的前提下分类：配额/额度、401/403、429、超时、提供商不可用和瞬态故障。遇到这些错误时，先尝试专用浏览器提供商，再尝试免费 HTTP 提供商。验证错误、显式取消或模糊配置不会静默回退。

浏览器提供商使用与个人配置文件隔离的 Chrome 会话，访问已配置的免费搜索引擎，提取标题/URL/snippet，并返回 `dsh-web` 的规范化词汇。每次尝试都有超时、结果限制和保证清理。如果 Chrome 未安装或无法启动，该错误会转换为可恢复的不可用状态并继续回退链。

免费 HTTP 路线是最后手段，必须容忍不完整 HTML、反机器人页面、重定向和无结果。Bing 作为初始搜索引擎；DuckDuckGo 作为替代。来源按 URL 去重，绝不伪造引用。

最终响应保留来源，并增加所使用提供商和已尝试路线的不敏感元数据用于诊断。错误消息不包含密钥、token、header 或带凭据的 URL。

## 验收标准

- 主要提供商的模拟额度错误会到达 Chrome/HTTP 并返回来源。
- 401、429 和超时会触发回退；用户取消不会触发回退。
- Chrome 使用专用配置文件，并在完成或失败时关闭。
- Bing 和 DuckDuckGo 按可配置顺序测试，并在获得有效结果时停止。
- 重复来源被删除，并遵守 `maxResults`。
- 所有路线均不可用时，返回包含已尝试路线且不含秘密的结构化错误。
- 测试使用 fixtures 保持确定性；独立 smoke 在 Chrome 可用时验证真实导航。

## 晋升

实现先集成到 `main`，执行聚焦测试、typecheck、build 和相关 gates。只有全部绿色才创建/晋升 `stable`；存在失败或未审查变更时，不进行 push 或晋升。
