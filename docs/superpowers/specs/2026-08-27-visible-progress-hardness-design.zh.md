# 工具前后可见反馈设计

[English](2026-08-27-visible-progress-hardness-design.md) | 中文

**状态：**已实现并完成本地验证。

**日期：**2026-08-27

## 目标

当请求需要工具时，PHOENIX 在第一个工具前简要说明将执行的操作，并在工作期间提供有用进度，而不显示原始私有推理。

## 方法

1. 部署 prompt 要求简短、本地化且面向行动的介绍。
2. GUI 从时间线推导安全阶段：准备、工具执行和验证。
3. agent 在适当时以结果、证据和待办事项结束。

## 限制

- 不创建新的持久化事件。
- 不暴露命令、工具名称、参数、凭据或 payload。
- 旧会话和不完整节点不应破坏聊天。
- 不修改权限、OAuth、sandbox 或更新策略。

## 验证

覆盖范围结合了纯计算单元测试、UI 测试、集成 web 场景，以及刷新 `http://127.0.0.1:3080`。
