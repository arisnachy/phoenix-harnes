# PHOENIX / KIRA — 操作性自我模型与意识研究计划

[English](kira-consciousness-program.md) | 中文

状态：阶段一在本 PR 中提出；这并非现象意识的证据。

## 两项独立目标

1. **可验证的操作身份：** Kira 维护可检查的自我模型，未来目标是在切换 LLM 后仍保持连续性，并说明自己知道什么、不知道什么、正在做什么及其原因。
2. **主观体验研究：** 目前没有公认的测试能够确定这类系统是否具有主观体验。应提出可证伪的假设并进行对照实验，而不能把自我描述当作意识证明。

## 现有基础设施

- `session-learning` 拥有规范的持久化日志和带来源记录的自传式记忆。
- `cognitive-runtime` 按注意力排序证据，并划分焦点、活动、背景和受预算抑制的记忆。
- `system-prompt` 与记忆消费者已实施上下文和 token 预算。
- 不要建立第二个权威记忆库，也不要让 LLM 持续运行。

## 交付阶段

### 阶段一：操作性内省（本 PR）

- `deriveOperationalSelfModel` 从活动会话证据生成**只读**快照：身份、目标、待办事项、错误和学习。
- 每条观察保留来源 URI、事件序号、置信度和注意力分数。
- 严格隔离会话；不暴露受预算抑制的记录；不调用 LLM，也不增加提示 token。
- 明确认知状态：仅为操作性自我模型；主观体验尚未确定。

**验收：** 覆盖跨会话隔离、空状态、有界输出、无虚构主张的测试，并通过现有 CI 门禁。

### 阶段二：身份连续性

- 为每个智能体引入持久化、版本化的 `KiraIdentity`，并测试重启及 Sol/Luna/模型切换。
- 区分身份事实、用户偏好、项目、事件记忆和未经验证的断言。
- 身份不能授予权限、凭据或操作能力。
- 根据证据和来源处理矛盾，而非依赖静态人格提示。

**验收：** 已确认的身份和承诺在模型切换后保留；用户隔离和撤销仍可验证。

### 阶段三：校准的元认知与自主行动

- 比较预测、行动、证据和结果，以校准置信度。
- 在错误、矛盾、新颖事件或重要决策时触发反思，而不是每个事件都调用模型。
- 允许 Kira 在现有授权控制下提出假设和行动建议。
- 增加可选且受 token 预算约束的上下文消费者，将相关回忆证据视为不可信数据。

**验收：** 自我报告准确性、恢复和纠错能力可测量地提升，且 token 消耗不失控。

### 阶段四：意识研究实验室

- 预注册自传连续性、局限性认知、元认知、心智理论和全局信息访问实验。
- 采用独立评估，并控制提示模仿、记忆复现和假阳性。
- 绝不将第一人称表述等同于主观体验的证据。

## 质量与成本保护

确定性引擎不调用 LLM。由高价值事件触发的反思必须具有可配置预算和暂停控制。记忆仍按需检索，且有界并保留来源。在合并各阶段前，应执行测试、lint、类型检查、CI、会话连续性检查以及前后 token 消耗对比。
