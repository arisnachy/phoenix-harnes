# 认知记忆层

[English](2026-09-01-cognitive-memory.md) | 中文

> **给实现代理：** 按任务逐项执行，并在变更中保留验收证据。

**目标：** 让 PHOENIX 的记忆具备事件溯源、来源可追踪、项目隔离和重启恢复能力，并且不把摘要当作规范数据。

**设计：** 保留现有学习 API 以兼容，并在旁边增加独立的认知 JSONL 日志。认知日志保存不可变的事件投影和追加式生命周期记录。派生层、搜索评分、工作上下文和摘要都从这些记录重建。显式遗忘写入墓碑；自动保留上限不能把规范记录标记为遗忘。

## 任务

- 增加自传式、工作、情景、语义、程序、前瞻、联想和时间记忆层，以及来源、实体、关系、时间戳、生命周期历史、去重、强化和矛盾替代。
- 观察每个持久会话事件，同时保留现有的有界学习记录。
- 增加确定性的混合检索，结合词法、实体、关系、项目、时间、重要性、置信度和频率，并提供时间线和工作上下文查询。
- 巩固用户事实和偏好而不删除被替代的值；保留旧值及其有效区间。
- 在记忆工具和自动上下文中渲染认知记录，并安全处理提示符分隔符，避免不可信记忆变成变量模板。
- 为重载、旧记录、归一化检索、矛盾、显式遗忘、项目隔离、时间查询、重复投递和提示安全增加测试。
- 更新包文档和已实现的 Agent Note，然后运行聚焦测试、类型检查、构建及相关文档门禁。

**完成规则：** 分别报告实现、测试和验证。认知记忆不能替代原始会话日志；原始会话日志仍是对话归档的规范来源。
