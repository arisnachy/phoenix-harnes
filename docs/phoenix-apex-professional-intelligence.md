# PHOENIX APEX — professional research and delivery

English | [中文](phoenix-apex-professional-intelligence.zh.md)

## Scope

APEX extends HARDNESS and the existing governed web research tools; it is not a separate assistant and does not replace the Kira task lifecycle.

## Implemented slice

- The expert research contract selects the professional discipline from the research domain and lists technical requirements, evidence gaps, and presentation constraints.
- `research_investigate` now returns that contract after examining actual source receipts; the optional `depth: expert` mode increases bounded source coverage.
- Expert mode reads up to sixteen documents across up to eight configured search batches, seeking four independent source owners with a 108-second acquisition limit and stopping early when enough evidence is read.
- Standard and deep modes preserve the prior latency budgets, while the HARDNESS guide applies specialist depth and evidence-backed visuals to any discipline.

## Evidence and visual rules

Search results and relevant excerpts are not proof. Multiple independent owners do not automatically verify individual statements. Medication doses require actual patient context and reference checking. Charts must use authentic numeric data with source, date and units; images must be relevant and traceable, should load without blocking text, and cannot replace a real deliverable.

## Verification

Run focused Vitest suites, TypeScript checks, snapshot tests and Windows gates, then measure research accuracy, client rendering and end-to-end outcomes before claiming the system is production ready.

## Limitations

This slice does not certify expert-superhuman performance, implement universal scholarly full-text connectors, automatically generate referenced images or guarantee sub-second remote image loading.
