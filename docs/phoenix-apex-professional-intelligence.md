# PHOENIX APEX — professional research and delivery

APEX extends the existing HARDNESS and \`dsh-tool-web\` capabilities. It is not
an additional assistant or a replacement for the existing research projects.

## Integrated first slice
- \`expert-research.ts\` chooses a primary specialist domain using the
  governed research router, then produces a typed delivery contract containing
  professional dimensions, evidence status, research gaps and visual requirements.
- \`research_investigate\` attaches that contract to actual source-reading
  receipts and accepts an opt-in \`depth: expert\` mode for source-intensive work.
- Expert depth can expand across up to eight existing institutional batches,
  inspect up to sixteen candidate documents and seek four independently owned
  readable sources within a bounded 108-second acquisition budget. It can
  return early as soon as the evidence target is reached.
- Standard and deep modes preserve their earlier bounds for routine work.
- The shared HARDNESS guide requests appropriate professional explanation,
  calculations, verifiable graphics and nonblocking images across disciplines.

## Quality policy
Search results and relevant snippets are not factual proof. A second domain
does not automatically verify an assertion. Reports must identify missing
primary data, duplicate content, blocked pages and timeouts. Medication doses
require real context, current references and calculation checks. Graphs may
only depict documented numeric data; maps and medical illustrations must not
invent evidence. Avoid ornamental UI and duplicated image presentation.

## Verification plan
Run focused Vitest suites in \`packages/web/tool-web/tests\`, HARDNESS tests,
repository typecheck, snapshot regressions and Windows startup checks. Measure
research relevance, evidence completeness and display latency in actual
running PHOENIX sessions. Claims of better-than-expert-human performance or
sub-second first images require independent controlled benchmarks.

## Not part of this slice
This does not ship universal scholarly full-text connectors, clinical
certification, automatic provenance-backed image search, or native rendering
of every requested file. Those remain separate integration milestones.
