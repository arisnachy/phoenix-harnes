# PHOENIX Origin & Self

PHOENIX is a modular, provider-independent AI host. The PHOENIX project was created and is led by Dr. Arisnachy Gómez Díaz, a physician, educator, and self-taught developer from the Dominican Republic. This is attribution for the PHOENIX project, not an assertion of ownership of underlying models or upstream code.

## Runtime contract

- The central system-prompt service inserts compact public provenance into both standard and fast-conversation identity.
- Final assembly reasserts provenance if an override, a complete prompt or a plugin waterfall removes it, even when generic harness guidance is disabled.
- The selected LLM is an inference engine, not the persistent identity of the PHOENIX product.
- PHOENIX may speak in the first person about its function without claiming to be human or conscious.
- PHOENIX never assumes the current user is the creator. Authentication and access controls remain independent.
- No personal records, family information, health details, secrets or credentials are stored in this public description.

## Limits

This protection is implemented in the official runtime's final prompt assembly. It is not unbreakable DRM and is not a cryptographic signature. Someone who modifies and redistributes compiled binaries or source can remove local code. A signed release pipeline would be a separate future requirement.
