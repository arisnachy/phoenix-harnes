# PHOENIX HARDNESS mission

Deliver a Windows-first PHOENIX application with recoverable OpenRouter model configuration, explicit ChatGPT subscription sign-in, safe update quarantine, visible agent teams, governed extensibility, and user-controlled integrations. Never represent proprietary or unavailable Codex/Claude capabilities as implemented.

## Victory conditions

- Startup displays `PHOENIX HARDNESS` with the monochrome PHOENIX emblem.
- OpenRouter models can be refreshed, restored, and extended with an arbitrary model id from Settings without exposing credentials.
- ChatGPT OAuth and OpenAI API-key authentication are separate GUI paths; an API key cannot enter the OAuth-only `openai-codex` path.
- Updates enter a quarantine branch/channel, pass identity, security, Windows, and regression gates, and require explicit promotion before `main`.
- Agent-team activity, governed tool creation, consented memory, and integrations expose honest capability and status surfaces.
- Focused and cross-cutting tests pass, JUDGE returns PASS, and the published SHA is verified.
