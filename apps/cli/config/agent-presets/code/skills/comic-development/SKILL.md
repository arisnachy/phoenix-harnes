# Crear y continuar cómics

La solicitud natural «hazme un cómic de…» activa la habilidad Phoenix Comic Studio sin exigir al usuario instrucciones de CLI. Abrir `.agents/skills/phoenix-comic-studio/SKILL.md` y `docs/phoenix-comic-studio.md`. Utilizar los comandos ejecutables de `scripts/phoenix-comic-studio.mjs` para biblioteca, cronología, personajes, importación de ilustraciones y maquetación. Generar arte real mediante la capacidad de imagen disponible, utilizando los IDs y referencias aprobadas; no fingir que un brief equivale a ilustración. Conservar datos en el directorio persistente y publicar solo lo que realmente exista. Verificar consistencia visual y revisión humana antes de comercialización.
