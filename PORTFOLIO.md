## Selected projects

### 01 — PHOENIX | Universal AI agent harness

[Source code](https://github.com/arisnachy/phoenix-harnes) · [Documentation](https://github.com/arisnachy/phoenix-harnes/blob/main/README.md)

**Challenge:** AI tools are often fragmented across providers and workflows, making advanced automation difficult to adopt.

**Approach:** A provider-agnostic, local-first AI environment designed around model selection, tools, multi-agent execution, continuity, recovery, and evaluation.

**Outcome:** A public, actively developed codebase with a Windows installer, Web UI, VS Code integration, and a documented stable update process. Capabilities are released incrementally and subject to verification.

**Skills:** Agent orchestration · AI integration · Software engineering · Automation · Release engineering

### 02 — HealthIA ONE | AI-assisted health continuity

[Source code](https://github.com/arisnachy/healthia-one) · [Product demo](https://youtu.be/44LfVn9pPdU) · [Architecture](https://github.com/arisnachy/healthia-one/blob/main/docs/ARCHITECTURE.md)

**Challenge:** Fragmented health information and unfinished follow-up tasks between clinical encounters.

**Approach:** A patient-owned, event-driven health continuity agent that converts evidence and unfinished work into persistent, consent-aware missions, with explicit human authority where required.

**Demonstrated outcome:** The project documentation and judging demo describe workflows that identify missing laboratory evidence, prepare for appointments, detect missing post-visit documentation, and close missions when supporting evidence arrives. These demonstrations use a synthetic patient scenario and do not establish clinical effectiveness in real patients.

**Skills:** Healthcare AI · Python · Google ADK · Gemini · Workflow design · Safety and evidence verification

### 03 — CINEMIND Studio | AI-native media production

[Source code](https://github.com/arisnachy/cinemind-studio) · [Documentation](https://github.com/arisnachy/cinemind-studio/blob/main/README.md)

**Challenge:** AI-generated media requires coordination across story development, visual continuity, rendering, and quality review.

**Approach:** An agentic streaming and creative production environment designed to create original fictional universes and coordinate multimodal production, with structured narrative memory and shared storyboard boundaries.

**Outcome:** A public project documenting an interactive streaming UI, a Python FastAPI backend, Google ADK, Gemini, configurable video generation, and media composition with FFmpeg.

**Skills:** Multimodal AI · Creative automation · Python · FastAPI · Cloud architecture · User experience

## How I approach real-world problems

1. Listen to the people who experience the problem and understand their workflow.
2. Identify a high-value opportunity where AI or automation can help.
3. Build a practical prototype using tools that fit the organization's resources.
4. Test results against concrete evidence and protect sensitive information.
5. Explain the solution in accessible language and help users adopt it.
6. Improve based on feedback rather than assuming technology alone solves the problem.
